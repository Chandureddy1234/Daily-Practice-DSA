def is_vowel(letter):
    return letter in 'aeiouy'

def score_words(words):
    score = 0
    for word in words:
        vowels = sum(1 for letter in word if is_vowel(letter))
        score += 2 if vowels % 2 == 0 else 1
    return score

1. First Repeating Element
Solved
Difficulty: EasyAccuracy: 32.57%Submissions: 340K+Points: 2Average Time: 15m
Given an array arr[], find the first repeating element index. The element should occur more than once and the index of its first occurrence should be the smallest.

Note:- The position you return should be according to 1-based indexing. 

Examples:

Input: arr[] = [1, 5, 3, 4, 3, 5, 6]
Output: 2
Explanation: 5 appears twice and its first appearance is at index 2 which is less than 3 whose first the occurring index is 3.
Input: arr[] = [1, 2, 3, 4]
Output: -1
Explanation: All elements appear only once so answer is -1.
Constraints:

1 ≤ arr.size() ≤ 106
0 ≤ arr[i] ≤ 106

solution:
from collections import Counter
class Solution:
    def firstRepeated(self, arr):
        # code here 
        count = Counter(arr)
        
        for i, num in enumerate(arr):
            if count[num] > 1:
                return i + 1
            
        
        return -1

Given an array of positive integers arr[], return the second largest element from the array. If the second largest element doesn't exist then return -1.

Note: The second largest element should not be equal to the largest element.

Examples:

Input: arr[] = [12, 35, 1, 10, 34, 1]
Output: 34
Explanation: The largest element of the array is 35 and the second largest element is 34.
Input: arr[] = [10, 5, 10]
Output: 5
Explanation: The largest element of the array is 10 and the second largest element is 5.
Input: arr[] = [10, 10, 10]
Output: -1
Explanation: The largest element of the array is 10 and the second largest element does not exist.
Constraints:
2 ≤ arr.size() ≤ 105
1 ≤ arr[i] ≤ 105

solution:
class Solution:
    def getSecondLargest(self, arr):
        # code here
        new = sorted(set(arr))
        if len(new)<=1:
            return -1
        else:
            return new[-2]

		# code here

You are given two arrays a[] and b[], return the Union of both the arrays in any order.

The Union of two arrays is a collection of all distinct elements present in either of the arrays. If an element appears more than once in one or both arrays, it should be included only once in the result.

Note: Elements of a[] and b[] are not necessarily distinct.
Note that, You can return the Union in any order but the driver code will print the result in sorted order only.

Examples:

Input: a[] = [1, 2, 3, 2, 1], b[] = [3, 2, 2, 3, 3, 2]
Output: [1, 2, 3]
Explanation: Union set of both the arrays will be 1, 2 and 3.
Input: a[] = [1, 2, 3], b[] = [4, 5, 6] 
Output: [1, 2, 3, 4, 5, 6]
Explanation: Union set of both the arrays will be 1, 2, 3, 4, 5 and 6.

Constraints:
1 ≤ a.size(), b.size() ≤ 106
0 ≤ a[i], b[i] ≤ 105

solution:
class Solution:    
    def findUnion(self, a, b):
        # code here
        setA = set(a)
        setB = set(b)
        
        return setA.union(setB)
